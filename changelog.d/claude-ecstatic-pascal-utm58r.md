### Added

- <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>U</kbd> takes a waiting update, without reaching for the sidebar's **Update Ruminate** item. It does nothing when no update is waiting, just as that item only appears when one is, and anything you have written but not yet saved is stored on this device before the page reloads — so a mistyped shortcut cannot carry it off with the old copy. The key is listed in the <kbd>?</kbd> reference with the rest.
