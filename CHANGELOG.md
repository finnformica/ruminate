# Changelog

The changelog is the [`changelog/`](changelog/) folder: one file per change,
under the week it was written in.

It is kept that way so that two branches open at once never touch the same
file, and so nothing has to be folded together before an entry can be read.
The single document is assembled at the point of reading — in the app, at
**What's new** in the sidebar, where it is one page of every release.

See [docs/changelog.md](docs/changelog.md) for the format, and
`.claude/skills/changelog` for how to write an entry.
