### Fixed

- Right-clicking a row on the Views page opens the row's menu again. It is the same menu the row's **⋯** button in the sidebar has: a note's row opens the note's menu, and a block's row opens the block's — **Copy**, **Copy link to block**, **Share…** and **Remove from Views** — with none of the editing a note's own block menu carries. The same goes for the ⌘K palette's rows, and for a press-and-hold on a phone. Before, a right-click there showed the browser's menu instead.
- A block view's **⋯** menu in the sidebar is that same block menu, with **Move up** and **Move down** ahead of it in the manual sort. **Remove from Views** wears the delete icon.
- A sidebar row's **⋯** menu no longer flashes in the top-left corner as it closes. Clicking away from an open menu briefly drew it at the page's corner; it now fades out where it was.
