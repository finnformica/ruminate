### Changed

- Offline, a note's header says **Saved offline** once an edit is on this device. "Saving…" still shows while the edit is being written, and gives way to **Saved offline** with the offline icon until you are back online and it syncs. It used to keep spinning "Saving…" until the network came back, over an edit that had long been saved.
- The sidebar's sync status now reads **Saving…** while a save is on its way to the cloud. It is the same word the note's header uses for the same moment, where the sidebar used to say "Syncing…".
