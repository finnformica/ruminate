### Added

- A board's pictures can be captioned and tagged by Claude. **Suggest tags** — the sparkles in a picked picture's title bar — asks Claude for a caption and a location, fixture and material, picking from the values already on the board and adding a short new one where none fits; it only fills in what is empty, as one change with one **Undo**. Under Settings → API, paste your own Anthropic API key — kept on the server, never shown again — to switch it on.
