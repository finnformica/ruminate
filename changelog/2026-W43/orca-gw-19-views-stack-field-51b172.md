### Added

- Root lists every note, and every page starts from it. It is first in the sidebar, and it is an outline like any note: open a note there to see its blocks, rename it, or move it up or down. Its filter and sort search every note. A note opened from search, a link or the calendar reads Root › note, and Back or <kbd>⇧</kbd> <kbd>F</kbd> steps down to Root.
- Save as view keeps the whole path you walked. Choose **Save as view** in a note's menu at any depth: the View opens again as Root › Tasks › Todos, with each step's filter, and Back goes down it one step at a time.
- A View shows the path it opens with, in the sidebar and in the search palette. After its name, in grey, it shows the steps below it, for example "Todos Root › Tasks". A View whose path has moved opens at its own place, straight from Root.

### Changed

- A board inside a note is a row like a note's, with the board's icon in place of a bullet. It opens and folds as any row does; it used to be a card.
- Manage a View where it is listed. Right-click a View in the sidebar, or press and hold it on a phone, for the same menu as its **⋯**: rename it, move it, or remove it from Views.
- A note's icon at the top of its page opens Root, the list of every note. Earlier this week it opened the Views page.
- <kbd>Enter</kbd> in the search palette opens the top result. It used to open the full results page, which is gone with the Views page.

### Removed

- The Views page is gone. Your Views are in the sidebar and in the search palette, and the list of every note is Root.

### Fixed

- Tap a note's or a board's icon at the top of its page to go to Root, on a phone too. One tap now lands: the icon's tap area is bigger on a touch screen, and a board's icon is a link now.
- Notes show as they arrive on a new device. A first sign-in in a fresh browser used to show nothing for a long time, and each reload showed a little more.
