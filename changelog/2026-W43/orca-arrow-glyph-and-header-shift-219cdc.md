### Added

- Typing `->` in a block shows an arrow (→) when you are not editing it. The note keeps `->`, so editing and markdown export show what you typed. Inside code, `->` stays as typed.

### Fixed

- A heading no longer moves the rows below it when you start or stop editing it. Its row used to grow by up to a pixel while edited; now it keeps the same height on every heading level, on a computer and on a phone.
