### Added

- Link a block into a second place from its menu, with no copying. A block's right-click menu, and its long-press sheet on a phone, offer **Add downstream link…**, which picks a block to put beneath this one, and **Add upstream link…**, which picks a block or a note to put this one beneath. Either opens the search palette with the blocks on screen suggested first; the block then lives in both places, as a pasted one does. Until now the only way was to paste a copied block, which a phone cannot do.
