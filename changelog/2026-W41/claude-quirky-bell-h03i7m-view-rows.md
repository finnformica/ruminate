### Changed

- A note can be removed from Views and added back, as a block can. **Remove from Views** in a note's menu — on its sidebar row, on the Views page or in the open note — takes it off the list and nothing else: it is still found by search, still in **Recent**, still on the calendar if it is a daily or weekly note, and still opens from any link or its address, with the filter and sort it saved. **Add to Views** in the same menu puts it back where it was.
