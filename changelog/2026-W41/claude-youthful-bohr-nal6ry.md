### Changed

- A note no longer ends in an empty paragraph. One used to be kept at the bottom of every note, whatever it held, as the row to click into; the note now ends where its last block does, and a click in the room beneath it adds a block at the end and opens it for typing — or opens the last block, when that is already an empty one.
- Pictures, link cards and code blocks sit in one frame. A code block is now set in from its row's edges as a picture and a link card are, with the same corners, and all three stand as far from the row's right edge as from its left, where the chevron and the marker are; selecting a code block outlines the row around its panel rather than colouring the panel's own border, and a code block can be dragged narrower and kept to a side as a picture can, with **Align** and **Full width** in its menu.
